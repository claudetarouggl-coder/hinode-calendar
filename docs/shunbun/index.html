よくある質問

2027年の春分の日はいつですか？
2027年3月21日（日曜日）です。
春分の日は昼と夜の長さが同じですか？
厳密には同じではありません。東京では昼のほうが夜より約8.7分長くなります。日の出・日の入りが太陽の上端を基準に定義されていることと、大気差で太陽が浮き上がって見えることが理由です。詳しくは昼と夜の長さのコラムをご覧ください。
2027年の春分の日は確定していますか？
春分の日は国立天文台が太陽の動きから算出し、前年2月に発表する「暦要項」の官報掲載で正式に決まります。本ページの日付は天文計算に基づく理論値で、正式決定前の年については予測値としてご利用ください。
春分の日はぼたもちを食べる日ですか？
春のお彼岸にはぼたもちをお供えする・食べる習慣があります。春分の日はその彼岸の中日にあたります。
