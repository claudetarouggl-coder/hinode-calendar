春分・秋分、昼と夜の長さは同じではない

2026年の秋分の日（9月23日）、東京の昼の長さは12時間08分で、夜より約7.8分長い計算になります。2027年の春分の日（3月21日）も同様に、昼は夜より約8.7分長くなります。「春分・秋分は昼と夜の長さが同じ」というのはよく知られた話ですが、実際に計算すると昼のほうがわずかに長いのです。

理由① 日の出・日の入りは太陽の「端」が基準

日の出・日の入りの時刻は、太陽の中心ではなく、太陽の上端が地平線に触れる瞬間として定義されています。太陽の視直径はおよそ32分角（0.53度）で、その半径にあたる約16分角の分だけ、太陽の中心が地平線に達するより前に「日の出」となり、地平線に達したあとに「日の入り」となります。

理由② 大気差で太陽が浮き上がって見える

もう一つの要因は大気差（大気による光の屈折）です。地平線付近では大気の密度差によって光が曲がり、実際の位置より約34分角も高い位置に太陽があるように見えます。この浮き上がり効果によって、太陽が幾何学的にはまだ地平線の下にあっても見かけ上は地平線の上に顔を出すため、日の出はさらに早く、日の入りはさらに遅くなります。

合計するとどのくらい昼が長くなるか

視半径と大気差をあわせると、日の出・日の入りはそれぞれ地平線から約50分角（0.83度）浮き上がった状態で定義されていることになります。太陽の高度が変化する速さは季節や緯度によって異なるため単純な換算はできませんが、実際に本サイトの計算エンジンで東京の秋分・春分の昼の長さを求めると、上記の通り約7.8〜8.7分ほど昼が長くなっています。

本当に昼と夜が同じ長さになるのはいつか

秋分・春分そのものではなく、その前後の日に昼の長さが12時間ちょうどに最も近づきます。2026年の東京では、秋分（9月23日）の3日後にあたる9月26日ごろに昼の長さが最も12時間に近づきます（下表）。2027年の春分（3月21日）では、4日前の3月17日ごろが最も12時間に近い日です。「春分の数日前」「秋分の数日後」に昼夜がほぼ同じ長さになるといわれることがあるのはこのためです。

よくある質問

秋分・春分は本当に昼と夜が同じ長さなのですか？
厳密には違います。東京の場合、秋分は昼のほうが約7.8分、春分は約8.7分長くなります。日の出・日の入りの定義（太陽の上端基準）と大気差が理由です。
なぜ日の出・日の入りは太陽の中心ではなく端を基準にするのですか？
肉眼で「太陽が出た」「沈んだ」と判断しやすいのが太陽の上端だからです。国立天文台をはじめ、世界的にこの定義が使われています。
昼と夜が本当に同じ長さになるのはいつですか？
2026年の東京では秋分の3日後の9月26日ごろ、2027年の春分では4日前の3月17日ごろです。
