よくある質問

2026年の冬至はいつですか？
2026年12月22日です。翌年以降は12月21日または22日になります（年によって変わります）。
冬至は日の出が最も遅く、日の入りが最も早い日ですか？
いいえ。日の入りが最も早いのは冬至より2週間ほど前、日の出が最も遅いのは年明けの1月上旬です。詳しくは解説記事をご覧ください。
冬至の昼はどのくらい短いのですか？
東京では9時間44分です。夏至より約4時間50分短く、これが一年の最小値です。
